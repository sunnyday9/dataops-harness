## Agent skills

### Issue tracker

Issues and specs are tracked as GitHub Issues in `sunnyday9/dataops-harness` via `gh`. See `docs/agents/issue-tracker.md`.

### Triage labels

Uses the default triage labels (`needs-triage`, `needs-info`, `ready-for-agent`, `ready-for-human`, `wontfix`). See `docs/agents/triage-labels.md`.

### Domain docs

Single-context repo layout (`GLOSSARY.md` and `docs/adr/` at the repo root). See `docs/agents/domain.md`.
